## Lista de Exercícios

### Lista 1: Análise Estatística e Espectral de Dados de Marés (`./lista-01/`)
Esta lista de exercícios visa analisar dados horários de nível do mar de 2020 coletados em duas estações maregráficas do litoral paulista: Cananéia e Ubatuba. O exercício aplica técnicas estatísticas básicas (média, desvio padrão, mediana, etc.), análise espectral via transformada de Fourier, e comparações mensais para caracterizar o comportamento das marés oceânicas nessas localidades, incluindo correlações entre as estações e identificação de padrões sazonais.
 
**Script:** `amaroc_L1_adriano_caversan.m`

---

### Lista 2: Análise Harmônica de Marés Oceânicas (`./lista-02/`)

Esta lista aplica o **método harmônico** de análise e previsão do nível do mar e de correntes de maré usando o toolbox `t_tide`. Os dados abrangem três localidades do litoral paulista: Cananéia, Ubatuba e a região costeira de Santos.
 
**Script:** `amaroc_L2_adriano_caversan.m`

#### Toolbox utilizado

`t_tide` — Pawlowicz, R., Beardsley, B., Lentz, S. (2002). Classical tidal harmonic analysis including error estimates in MATLAB using T_TIDE. *Computers & Geosciences*, 28, 929–937.
